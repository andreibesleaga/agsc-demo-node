Skill packs

SummaryOne pack per Cluster, each a single SKILL.md of text (AGSC-07-19).

  • advanced: Larger agent systems built by combining simpler patterns, such as a research system with a lead agent and parallel searchers.
  • antipatterns: Common mistakes in agent systems, how to recognise them, and how to avoid them.
  • classical: Established software patterns, such as the saga, applied to agent workflows.
  • cognitive-behavioral: Ideas from cognitive science, such as self-monitoring, turned into agent patterns.
  • data-retrieval: How agents find and use the right information, and how to measure whether they did.
  • ethics: Human control over autonomous systems, and their effects on people and the environment.
  • evaluation-testing: How to test agents and measure whether they work.
  • foundational: The basic building blocks of agents, such as loops, tools and ways of combining model calls.
  • future: Open research questions about agents, with what is known and what is not.
  • governance: Records, rules and checks that make agent actions accountable.
  • memory-cognition: How agents remember, forget and turn past work into reusable skills.
  • operations-reliability: Running agents in production, including handling failures, controlling cost and watching behaviour.
  • product: Product decisions for agents, such as how much an agent may do on its own.
  • protocols: Shared formats and addresses that let agents, tools and organisations work together.
  • reasoning-decision: How agents set goals, decide what to do next and know when to stop.
  • reference-architectures: Complete agent designs that combine several patterns into one working system.
  • sdlc: Building software with agents through phases, approval gates and reviews.
  • security: Threats to agents, and the designs that defend against them.
  • specs: How to state what an agent should do when its behaviour is not fully predictable.
  • topologies: Ways for several agents to work together, such as a shared workspace or a hierarchy.
