The basic building blocks of agents: loops, tools and ways of combining model calls.

Members

  • Agent-Graph Optimization: Treat an agent workflow as a graph of nodes, edges and prompts, and search that space with an evaluator, as GPTSwarm, AFlow and MASS do.
  • Agents as Tools: Wrap a specialist agent as a tool, so a calling agent can hand it one bounded task and keep control.
  • The Augmented LLM: A language model enhanced with retrieval, tools and memory that it uses actively, described by Anthropic as the basic building block of agentic systems.
  • Graph of Thoughts: Model LLM reasoning as a graph of thoughts and dependencies, so thoughts can be combined and refined, not only branched.
  • Parallelization: Run independent subtasks at once and combine the results, either by splitting the work or by running the same task several times.
  • Agent as State Graph: Express an agent as nodes, edges and shared state run in super-steps with checkpoints, as in LangGraph and Google's Pregel model.
  • Termination and Exit Conditions: Define in advance each way an agent loop ends, such as a final answer, a turn limit, or a pause for human input.
