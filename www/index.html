AgenticSystemCore Graph

SummaryAgent-system designs as a typed, cited graph, built by the AgenticSystemCore reference engine: the second node of the Agentic Knowledge Web.

Short cards on well-known agent-system designs, each written from the public sources it cites and joined to the others by typed links. This is the second node of the Agentic Knowledge Web, beside agenticsystemcore.com; each names the other in its discovery file. The AgenticSystemCore engine built every file here as static files: no server and no database run behind it.

Six ways to use this node

  • Read it as a wiki. Browse the concepts and the clusters, or use the search page, which runs in your browser. The NOW page lists what has gone stale.
  • Use it as an agent's memory. An agent starts at the discovery file, which gives a digest for each file it names, then reads llms.txt, llms-full.txt or the passages in chunks.jsonl. Every item page offers ten tools to an assistant in the browser (how they work).
  • Keep specifications alive. The node's own decision, card format and gate are items like any other, and the board shows its open tasks.
  • Take the skills. The skill packs give one file per cluster for an agent's tool folder, with a hash for every file.
  • Compose. The compose page turns the cards you tick into seven starting files, computed in your browser.
  • Work on the board. Pick an open task on the board and send your change as a pull request to the agsc-demo-node repository, which holds the published items. A person merges it.

The graph

The items and their typed links are published as JSON-LD, Turtle and N-Quads, in the format's published vocabulary. The graph explorer draws it, and the query page runs a SPARQL query over it in your browser. This node adds four terms of its own in domain/vocabulary.ttl: a failure mode, a safeguard, and the link guards against with its reverse. Beside every page sit a Markdown and a JSON-LD copy, for example the Markdown and JSON-LD of Blackboard. Every published change is a line of ledger.jsonl; the changelog lists the tagged versions.

Run your own node

The engine is the npm package agentic-system-core; its source is in the engine repository. To begin, read start here on agenticsystemcore.com.
