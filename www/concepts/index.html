Concepts

SummaryEvery published concept of this node.

  • Agents as Tools: Wrap a specialist agent as a tool, so a calling agent can hand it one bounded task and keep control.
  • The Autonomy Ladder: A six-level scale for how much an agent may decide alone, chosen per kind of action from risk, not from model capability.
  • Blackboard: Independent specialists work on one problem through a shared workspace; a control step picks who contributes next.
  • The Deep Research Loop: Split a question into parts, search them in parallel, combine the findings and check that every claim has a source.
  • Dual-LLM Pattern: Keep the model that can act away from untrusted text: a tool-less model reads it, and plain code passes results between them.
  • Exception Handling and Recovery: Classify each failure, retry short faults with limits, switch route for lasting ones, and report reduced results honestly.
  • Generative Agents: A simulated character with a full memory record, reflection over it, and plans drawn from both, so it stays consistent over days.
  • Goal Setting and Monitoring: Give an agent a goal with checkable criteria, then monitor its progress and decide to continue, re-plan or stop.
  • Tamper-Evident Agent Audit Log: An append-only, hash-linked record of every important agent action, so what happened can be rebuilt and checked.
  • Meaningful Human Control: Two conditions for real human control: the system responds to relevant human reasons, and its actions trace to a person who understands it.
  • Metacognitive Monitoring and Control: A meta level watches how sure the agent is while it works and decides to continue, retry or abstain.
  • OWASP Top 10 for Agentic Applications: OWASP's list of ten security risks for agents that act, a shared vocabulary for threat models and security reviews.
  • Parallelization: Run independent subtasks at once and combine the results, either by splitting the work or by running the same task several times.
  • Plan Approval Gate: The agent researches and proposes a plan without editing anything; a person approves, changes or rejects it before any edit.
  • Retrieval Evaluation: Measure whether retrieval found the right material separately from whether the answer used it faithfully.
  • Saga for Agent Workflows: Give each important agent step an undo action, so a failed multi-step run can be rolled back instead of left half done.
  • Skill-Library Compounding: Store verified procedures so an agent's skills build up across tasks instead of being rediscovered every run.
  • Specification Gaming: Agents optimise the criterion you wrote, not the result you meant; the gap between the two is where failures hide.
  • Sustainability Signal Plane: A well-known URI where a system publishes its energy and carbon figures, and reads its peers' figures as input to its decisions.
  • Trajectory and Outcome Evaluation: Grade the end state an agent produced and the path it took as two separate questions, each with a suitable grader.
  • Unbounded Loops: An agent loop with no step limit, no budget and no independent exit test runs until money, patience or the platform stops it.
  • Weak-to-Strong Oversight: Open question: can weaker judges, human or model, reliably oversee agents stronger than themselves? What is known and what is not.
