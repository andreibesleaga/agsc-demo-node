cost-control

SummaryEvery item tagged "cost-control".

  • Bulkhead Isolation: Give each agent, tenant or dependency its own bounded resource pool, so a fault or overload in one stays out of the others.
  • Prompt-Caching Layout: Put the stable prompt prefix first and variable content last so provider prompt caches can reuse it on later requests.
  • Record–Replay for Agent Tests: Record real model responses in one test run and replay them from a cassette on later runs, so tests run offline and repeat exactly.
  • Termination and Exit Conditions: Define in advance each way an agent loop ends, such as a final answer, a turn limit, or a pause for human input.
  • Thinking-Budget Control: Set how much reasoning a model spends per task class before the call, using effort levels and thinking settings that providers document.
  • Unbounded Loops: An agent loop with no step limit, no budget and no independent exit test runs until money, patience or the platform stops it.
