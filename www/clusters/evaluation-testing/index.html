How to test agents and measure whether they work.

Members

  • Error Analysis by Open and Axial Coding: Read traces, write open notes, then group them into a failure taxonomy, so the categories come from the data.
  • Golden Trajectories and Snapshot Tests: Store a known-good agent run as a test case and replay it on each change; Google's ADK and Anthropic describe tolerant ways to compare the results.
  • Idempotency Keys for Agent Actions: Attach a stable idempotency key to each side-effecting call so a retried or replayed request is executed once, as Stripe and Temporal describe.
  • Judge Calibration: Measure an automated judge against human labels before trusting its verdicts, and audit it for position, verbosity and self-enhancement bias.
  • Pass^k Reliability: Score an agent by the probability that all k repeated trials of a task succeed, rather than at least one.
  • Record–Replay for Agent Tests: Record real model responses in one test run and replay them from a cassette on later runs, so tests run offline and repeat exactly.
  • Trajectory and Outcome Evaluation: Grade the end state an agent produced and the path it took as two separate questions, each with a suitable grader.
