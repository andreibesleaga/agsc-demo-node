Parallelization

SummaryRun independent subtasks at once and combine the results, either by splitting the work or by running the same task several times.

Type
concept · kind pattern
Cluster
Foundational
Tags
concurrency, ensemble
IRI

Provenance
Imported from another source (origin imported, operator human:andreibesleaga)

Intent

Run independent subtasks at the same time and combine the results.

Context & Forces

Doing independent work in sequence wastes time.

Structure

Anthropic names two variants (Schluntz and Zhang, 2024): sectioning into parallel subtasks, and voting by running the same task several times.

Consequences & Trade-offs

Time is set by the slowest branch, and cost grows with each branch.
