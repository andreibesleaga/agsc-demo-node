Human-Only Merge Gate

SummaryAn agent works on its own branch and cannot approve or merge; a named human decides what reaches the main branch.

Type
concept · kind pattern
Cluster
Agentic SDLC
Tags
accountability, coding-agents, governance
IRI
https://patterns.agenticsystemcore.com/concepts/human-only-merge-gate/
Provenance
Imported from another source (origin imported, operator human:andreibesleaga)

Intent

Keep agent-authored changes out of the main branch until a human merges them.

Context & Forces

Prifti et al. (2026) note that self-review validates against the model that produced the output.

Structure

GitHub's Copilot cloud agent pushes to a single branch and cannot approve or merge its pull requests; a human does.

Consequences & Trade-offs

A human decides the merge, with the session log to review.
