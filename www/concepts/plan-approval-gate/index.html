Plan Approval Gate

SummaryThe agent researches and proposes a plan without editing source; a person approves, changes or rejects it before edits start.

Type
concept · kind pattern
Cluster
Agentic SDLC
Tags
human-oversight, coding-agents, governance

Provenance
Imported from another source (origin imported, operator human:andreibesleaga)

Intent

The agent proposes a plan without editing source; a person approves it before edits start.

Context & Forces

An agent that edits at once commits to an unseen approach.

Structure

In Claude Code's plan mode, the agent explores and proposes changes without editing source until a person approves.

Consequences & Trade-offs

Reviewers judge the approach, not a large diff.
