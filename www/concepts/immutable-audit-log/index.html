Tamper-Evident Agent Audit Log

SummaryAn append-only, hash-linked record of every important agent action, so what happened can be rebuilt and checked.

Type
concept · kind pattern
Cluster
Governance & Accountability
Tags
compliance, observability, persistence
IRI

Provenance
Imported from another source (origin imported, operator human:andreibesleaga)

Intent

Keep a checkable record of every important agent action that shows any change.

Context & Forces

OWASP lists repudiation and untraceability as threat T8 for agentic systems.

Structure

OWASP asks that AI-generated logs be cryptographically signed and immutable.

Consequences & Trade-offs

Incidents can be reconstructed from the log.
