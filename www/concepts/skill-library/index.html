Skill-Library Compounding

SummaryStore verified procedures so an agent's skills build up across tasks instead of being rediscovered every run.

Type
concept · kind pattern
Cluster
Memory & Cognition
Tags
self-improvement, persistence
IRI

Provenance
Imported from another source (origin imported, operator human:andreibesleaga)

Intent

Store capabilities known to work, so an agent's skills grow instead of being rediscovered.

Context & Forces

An agent that forgets a solution pays for it again.

Structure

Voyager (Wang et al., 2023) keeps a growing library of executable skills, uses self-verification, and builds complex skills from simple ones.

Consequences & Trade-offs

A bad skill changes behaviour, so review it like code.
